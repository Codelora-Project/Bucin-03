# Folder Asset Audio Musik

Letakkan file audio musik (`.mp3`) kamu di folder ini (`public/assets/`).

### Contoh Nama File MP3:
- `shape-of-my-heart.mp3`
- `sampai-jadi-debu.mp3`
- `perfect.mp3`
- `until-i-found-you.mp3`
- `monokrom.mp3`

Jika file `.mp3` belum dimasukkan, website akan secara otomatis memutar audio sampel *lofi/acoustic* sebagai *placeholder*.
